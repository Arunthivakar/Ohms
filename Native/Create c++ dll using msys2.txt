Install msys2 - link -> https://www.msys2.org/

run the below command in the msys2 terminal

pacman -S --needed mingw-w64-ucrt-x86_64-gcc
g++ --version

create a CppDll folder
now create a NativeLib.cpp file 

// NativeLib.cpp

extern "C" __declspec(dllexport)
int Voltage(int current, int resistance)
{
    return current * resistance;
}

extern "C" __declspec(dllexport)
int Current(int voltage, int resistance)
{
    return voltage / resistance;
}

extern "C" __declspec(dllexport)
int Resistance(int voltage, int current)
{
    return voltage / current;
}

in terminal navigate to the created folder 

cd /c/CppDll

run the below command to generate dll
g++ -shared -o NativeLib.dll NativeLib.cpp -static-libgcc -static-libstdc++


make sure the below settings

1. NativeLib.dll -> Properties -> Build Action = Content and Copy to output directory = Copy if Newer
2. dll available in this path bin\x64\Debug\net10.0-windows\NativeLib.dll
3. Debug configration to x64 for the wpf project and for c++ dll or x84 for c++ dll and wpf proj
4. check the below code in .csproj file

	<ItemGroup>
		<Content Include="Native\NativeLib.dll">
			<CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
			<TargetPath>NativeLib.dll</TargetPath>
		</Content>
	</ItemGroup>

GCC is a compiler; 
MSVCRT and UCRT are runtime libraries. They are not the same thing. 
Also, a MinGW-built DLL may require its corresponding runtime DLLs to be available on the target Windows machine.
